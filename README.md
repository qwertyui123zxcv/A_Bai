# 医药 ERP 业务流程全览

GMP 生产 + GSP 经营 · 双认证视角的医药行业业务流程知识沉淀。

## 这是什么

一份覆盖 **11 大核心业务流程** 的交付知识库，以「故事卡」的形式，系统梳理医药 ERP/WMS 实施中的业务逻辑与合规要点。

- **GMP**（药品生产质量管理规范，生产型企业）与 **GSP**（药品经营质量管理规范，经营/流通型企业）双线视角
- 采购、采购退出、生产、采购付款、物料检验不合格处理、质量复验、销售、销售退回、销售收款、WMS 仓储、商品养护共 11 个流程
- 其中采购、采购退出、销售、销售退回四个流程因 GMP/GSP 差异明显，分别拆成双版本

## 每张卡的结构

每个流程均按统一框架展开，便于快速检索与复用：

- 一句话目的 / 触发条件 / 前置上游
- 主线步骤（含流程可视化图）
- 关键单据与字段
- 异常与回退 / 下游衔接
- 上线后自检点
